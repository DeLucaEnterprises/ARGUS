# ARGUS demo photos

3 drone photos, shipped with the repo so anyone can run ARGUS with
no photos of their own. In the UI, click **USE DEMO PHOTOS** in
section 1 — it copies these into `data\input\`, then Run in section 2.

- `DJI_0066.jpg` — a small person, upper right (the test subject)
- `DJI_0065.jpg` — woods, no obvious person
- `DJI_0055.jpg` — open field by a river, no obvious person

Suggested first brief: `adult person, dark shirt` (fictional test
brief only — never a real person or a real case).
